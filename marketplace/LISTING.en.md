# Discord Shortcuts

Proposed free Marketplace listing. The product has not been submitted or approved.

## Description

Enable or pause your selected custom Discord keybinds with a Stream Deck key. Discord Shortcuts works with the ShortcutToggle userplugin for Vencord and shows the confirmed ON/OFF state from Discord. It reconnects after interruptions, indicates when Discord is offline and refreshes keys after page changes.

Select the action in Stream Deck to view the installed companion version, check GitHub releases, enable daily update checks and open setup or support links. GitHub installation is manual. Stream Deck manages native automatic updates for versions installed through Marketplace after approval.

Requires Windows 10 or later, Stream Deck 7.1 or later, desktop Discord with a source-built Vencord installation, and ShortcutToggle. The current companion settings interface is in French. The setup guide is available in English and French. The plugin is independent of Discord, Vencord and Elgato. It does not replace Discord's own Stream Deck plugin or run arbitrary macros.

Communication with ShortcutToggle stays on the same computer. No Discord login, token or password is requested. Optional update checks read public release metadata from GitHub.
